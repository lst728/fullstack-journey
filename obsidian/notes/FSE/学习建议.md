## 后端三大件
AI 全栈，后端这部分建议顺序是：**Spring Boot 单体 → Redis/RocketMQ/Nacos → Spring Cloud 微服务**。这样既能快速做出 AI 应用的后端，也能逐步理解大型系统的设计。
三个概念可以这样一句话理解：

- **Java单体**：一个“大盒子”，所有功能打成一个包，一起部署。
    
- **中间件**：盒子之间、盒子与数据库之间的“工具箱”，负责通信、缓存、消息、协调。
    
- **微服务**：把大盒子拆成很多“小盒子”，各自独立运行，再通过中间件连接起来。


**Spring Boot = Spring 框架 + 自动配置 + 起步依赖 + 内嵌服务器**
### 学习建议

1. **先补 Spring 核心**：IoC、DI、AOP、Bean 生命周期。
    
2. **再学 Spring Boot**：创建项目、REST、配置、数据访问。
    
3. **然后接中间件**：MySQL、Redis、RocketMQ。
    
4. **接着学安全**：Spring Security + JWT。
    
5. **最后进微服务**：Spring Cloud Alibaba、Nacos、Gateway、Sentinel。
    
6. **用项目驱动**：做一个博客、商城或 AI 问答后端。
## vibe coding前端
### 一、必须会的前端基础

不用手写每一行，但必须看得懂、改得动。

- **HTML/CSS**：语义化标签、Flex/Grid 布局、响应式、盒模型。
    
- **JavaScript**：ES6+、变量/函数/数组对象、异步 `async/await`、`fetch`、模块化。
    
- **DOM 与事件**：点击、输入、表单、条件渲染、列表渲染。
    
- **浏览器 DevTools**：Console 看报错、Network 看接口、Elements 调样式。
    

这是底线。否则 AI 写错了，你连问题在哪都不知道。

---

### 二、框架与工程化

前端 Vibe Coding 最常用的是 **React** 或 **Vue**，建议先选一个。

- **React**：组件、props、state、hooks（`useState`、`useEffect`）、路由。
    
- **Vue 3**：Composition API、`ref`、`reactive`、组件通信。
    
- **样式方案**：Tailwind CSS 最适合 AI 生成，配合 shadcn/ui、Ant Design、Element Plus。
    
- **工程工具**：Vite、npm/pnpm、Git。
    
- **API 调用**：axios/fetch、处理 loading/error/empty、跨域、环境变量。
    

这些不需要背 API，但要知道组件怎么拆、状态放哪、数据怎么流。

---

### 三、调试与验收能力

Vibe Coding 大量时间花在“AI 写错 → 你贴报错 → AI 改 → 你再验”。

- 会读控制台报错，能定位是样式、逻辑、依赖还是数据问题。
    
- 会用 React/Vue DevTools 看组件状态。
    
- 会看 Network，判断接口是否成功、跨域、流式响应。
    
- 会验收：响应式、移动端、加载状态、空状态、错误状态。
    
- 会 Git：提交、分支、回滚。AI 改乱了能退回去。
    

---

### 四、AI 协作能力

这是 Vibe Coding 的核心技能。

- **会写清晰 Prompt**：指定技术栈、文件结构、组件拆分、样式方案、响应式要求。
    
- **小步快跑**：一次只让 AI 做一个组件或一个功能，不要一口气生成整个项目。
    
- **要求解释**：让 AI 说明关键逻辑，方便你判断。
    
- **要求测试**：让 AI 补测试或至少给出手动验证步骤。
    
- **贴报错**：把完整报错、相关代码、期望效果一起给 AI。
    
- **控制依赖**：要求 AI 不随意引入新库，避免项目臃肿。
    

常用工具：Cursor、Claude Code、GitHub Copilot、[v0.dev](https://v0.dev/)、[Bolt.new](https://bolt.new/)、Lovable、Windsurf。前端 UI 生成，v0 特别适合。

---

### 五、可以交给 AI 的 vs 不能交给 AI 的

**可以交给 AI：**

- 样板代码、组件初稿、样式初稿、API 封装、测试初稿、文档。
    

**不能交给 AI：**

- 架构决策、安全、性能、用户体验、业务逻辑正确性、最终验收。
    
- 尤其注意：**API Key 绝不能放前端**，必须走后端代理。

### 六、最小技能清单

如果你只想尽快用 Vibe Coding 做前端，至少掌握：

1. HTML/CSS/JS 基础
    
2. React 或 Vue 其中一个
    
3. Tailwind CSS
    
4. Vite + Git
    
5. 浏览器 DevTools
    
6. 会写清晰 Prompt、会贴报错
    
7. 会部署到 Vercel / Netlify
    

学习顺序建议：  
**HTML/CSS/JS → React + Tailwind → Vite + Git + DevTools → Cursor/v0 → 项目实战 → 部署。**
