- `meta` 是空元素，用来描述页面的元信息。
    
- 它常用的属性是 `name`、`content`、`charset`、`http-equiv`。
    
- `name` 表示元信息的名称，`content` 表示对应的值。
    
- 所以“作者”要写成 `name="author"`，值放在 `content` 里。
记忆：**`name` 说明是什么，`content` 说明内容是什么。**
### 典型页面可以这样组织
```html
<body>
  <header>
    <h1>网站标题</h1>
    <nav>
      <a href="#">首页</a>
      <a href="#">关于</a>
    </nav>
  </header>

  <main>
    <section>
      <h2>第一部分</h2>
      <p>内容...</p>
    </section>

    <section>
      <h2>第二部分</h2>
      <p>内容...</p>
    </section>
  </main>

  <footer>
    <p>&copy; 2024 小鲤鱼</p>
  </footer>
</body>
```
各标签作用：

|标签|作用|使用要点|
|---|---|---|
|`header`|页头或区块头部|可放标题、logo、导航|
|`nav`|导航链接|主要导航区域|
|`main`|页面主要内容|一个页面只用一个|
|`section`|主题区块|通常带标题，表示一个独立主题|
|`article`|独立完整内容|如文章、帖子、评论|
|`aside`|侧边栏、补充内容|与主内容相关但非核心|
|`footer`|页脚|版权、联系方式等|
重构页面时，可以这样分：

- `header`：放 `<h1>HTML 学习</h1>`
    
- `main`：放学习记录、学习资源、图片、励志格言、联系我
    
- 每个主题用 `section` 包起来，并配 `<h2>`
    
- `footer`：放版权信息
### `<label>` 的 `for` 属性
写法：
```html

<label for="name">姓名：</label>
<input type="text" id="name" name="name">
```

作用：

- `for` 的值必须等于对应表单控件的 `id`。
    
- 这样点击“姓名：”这段文字，光标会自动跳到输入框里。
    
- 对复选框、单选框也很有用：点文字就能选中。
    

规则：

- `for="name"` 和 `id="name"` 要**完全一致**。
    
- 一个 `id` 在一个页面里只能出现一次。
- `required` 是表单控件的**布尔属性**，表示“必填”
