## 一、文档基础标签
```html
<!DOCTYPE html>   <!-- 声明文档类型，告诉浏览器这是html5 -->
<html lang="zh-CN"> <!-- 整个网页根标签，lang指定页面语言中文 -->
<head>            <!-- 头部：放网页元信息，页面不直接显示 -->
  <meta charset="UTF-8"> <!-- 编码，防中文乱码 -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0"> <!--移动端适配-->
  <title>网页标题</title> <!--浏览器标签页标题-->
</head>
<body>            <!-- 页面主体，所有看得见的内容都写在这里 -->
</body>
</html>
```
## 三、文本段落标签

```html
<p>段落标签，自带上下间距，块级元素</p>
<br>  <!-- 强制换行，自闭合 -->
<hr>  <!-- 水平分割线，自闭合，就是你代码里用到的 -->
<pre>预格式化文本，保留换行和空格（展示代码用）</pre>
```
## 四、文本行内修饰标签（不换行，行内元素）

```html
<b>加粗（仅视觉）</b>
<strong>加粗（语义强调，推荐用这个）</strong>
<i>斜体（仅视觉）</i>
<em>斜体（语义强调，推荐）</em>
<u>下划线</u>
<del>删除线</del>
<small>小号文字</small>
<span>通用行内容器，用来局部改样式，无语义</span>
```

## 七、容器标签（布局核心）

```html
<div>通用块级容器，大块布局，独占一行，无语义</div>
<header>页面头部（语义化，代替div做头部）</header>
<nav>导航栏</nav>
<main>页面主体内容（一个页面只能一个main）</main>
<aside>侧边栏</aside>
<footer>页面底部</footer>
<section>内容区块</section>
<article>独立文章内容</article>
```

> 优先用语义标签，简单页面可以先用 div 快速写。

## 九、表单标签（后面前端重点，收集用户输入）

```html
<form> <!--表单容器，提交数据-->
  <input type="text">  <!--单行输入框-->
  <input type="password"> <!--密码框-->
  <input placeholder="请输入内容"> <!--输入框-->
  <input type="button" value="按钮">
  <textarea>多行文本框</textarea>
  <label>标签，关联输入框</label>
  <select>下拉选择框</select>
</form>
```
### 示例1：
```html
<!--单行文本输入框-->
<input type="text" placeholder="请输入用户名">

<!--密码框，输入内容黑点隐藏-->
<input type="password" placeholder="请输入密码">

<!--普通按钮-->
<input type="button" value="普通按钮">

<!--提交按钮，点击会提交form表单数据-->
<input type="submit" value="提交表单">

<!--重置按钮，一键清空表单所有内容-->
<input type="reset" value="重置">

<!--单选框 radio 同一组name相同，只能选一个-->
<input type="radio" name="gender" id="man">
<label for="man">男</label>
<input type="radio" name="gender" id="woman">
<label for="woman">女</label>

<!--复选框 checkbox，可以多选-->
<input type="checkbox" id="html">
<label for="html">学习HTML</label>
```
### 示例2：
```html
<form action="/submit" method="post">
  <label for="username">用户名：</label>
  <input type="text" id="username" name="username" placeholder="请输入用户名" required>

  <label for="pwd">密码：</label>
  <input type="password" id="pwd" name="password" required>

  <label for="email">邮箱：</label>
  <input type="email" id="email" name="email">

  <label>
    <input type="checkbox" name="hobby" value="reading"> 阅读
  </label>

  <label>
    <input type="radio" name="gender" value="male"> 男
  </label>
  <label>
    <input type="radio" name="gender" value="female"> 女
  </label>

  <label for="city">城市：</label>
  <select id="city" name="city">
    <option value="bj">北京</option>
    <option value="sh">上海</option>
  </select>

  <label for="msg">留言：</label>
  <textarea id="msg" name="message" rows="4" cols="30"></textarea>

  <button type="submit">提交</button>
</form>

```
核心标签：

|标签|作用|
|---|---|
|`form`|表单容器|
|`input`|输入框，靠 `type` 变形状|
|`label`|标注文字，`for` 对应 `input` 的 `id`|
|`textarea`|多行文本|
|`select` / `option`|下拉菜单|
|`button`|按钮|

`input` 常用 `type`：

|type|作用|
|---|---|
|`text`|单行文本|
|`password`|密码|
|`email`|邮箱|
|`number`|数字|
|`date`|日期|
|`checkbox`|复选框|
|`radio`|单选框|
|`file`|上传文件|
|`submit`|提交按钮|
|`reset`|重置按钮|
|`hidden`|隐藏字段|

常用属性：

|属性|作用|
|---|---|
|`name`|提交时的字段名，必写|
|`value`|默认值 / 提交值|
|`placeholder`|提示文字|
|`required`|必填|
|`disabled`|禁用|
|`readonly`|只读|
|`checked`|默认选中（radio / checkbox）|
|`selected`|默认选中（option）|

`form` 本身：

html

<form action="/submit" method="post">

- `action`：提交到哪个地址
    
- `method`：提交方式，常用 `get` 或 `post`
